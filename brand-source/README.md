# Logo source

The Audiobook Project logo (a humpback leaping out of an open book) is generated by these scripts.
`public/brand/mark.svg`, `public/brand/icon.svg`, the icon PNGs and the logo in `views/_header.html`
all come from `whale7.py`'s `"q4"` pose.

- `whale7.py`: the humpback, drawn flat and bent into leap poses (`POSES`), plus the book and ripple.
- `marks2.py` … `marks6.py`, `leapfinal.py`, `leap2.py`: earlier rounds of logo exploration that
  `whale7.py` builds on (the book shape, the ripple ring, drops).
- `leapfiles.py`: writes the logo into the site. It keeps the header logo's hand-tuned viewBox.

```
python3 brand-source/whale7.py      # review sheet of the poses → brand-source/review.html
python3 brand-source/leapfiles.py   # rewrite mark.svg, icon.svg and the header logo
```

After `leapfiles.py`, re-render the PNG icons from `icon.svg` (for example with headless Chrome at
512×512, then `sips -z 180 180` for the 180px one).
